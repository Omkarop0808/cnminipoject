## Cross-Phase Integration & Wiring
- **Phase 1 -> Phase 2 (Surveillance to Attribution):** `RegistryWatcher` mutation callbacks seamlessly invoke `ProcessCache.resolve_pid()` and pass canonical schemas to `AlertManager`.
- **Phase 2 -> Phase 3 (Engine to Interface):** `AlertManager` and `EventRepository` publish via `websocket_hub.broadcast_sync()` to active browser connections and persist in SQLite WAL storage.
- **Phase 3 -> Phase 4 (Interface to Simulation):** The React `SimulationLab` triggers `POST /api/v1/test/simulate`, executing reversible attack vectors and reporting detection latency and rule hits.
